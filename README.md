# 日程本+

給學生用的手帳式日程本網頁，可以加到 iPhone 主畫面當成 App 使用。資料只存在手機本機。

## 功能
- **每日**：週日期列、今日課程（從課表帶入）、截止與考試、行程時間軸、待辦（可移到明天）、習慣打卡、心情與一句話日記
- **週計畫**：本週目標、七天總覽、習慣追蹤表、週記
- **月計畫**：月曆（標出行程 / 作業 / 考試）、點選日期預覽、本月目標、月記
- **課業**：課表（可設定科目顏色、教室、節次時間）、作業與考試清單（依截止日分組，顯示下一場考試倒數）
- 設定：每週起始日、週六課表、節次時間、習慣項目、匯出 / 匯入備份

## 部署到 Netlify
1. 到 https://app.netlify.com/drop
2. 把整個「日程本plus」資料夾拖進去（不需要 `.claude` 資料夾）
3. 拿到網址後，用 iPhone **Safari** 打開 → 分享 → **加入主畫面**

## 注意
- 資料存在該裝置的 Safari 中，換手機或清除 Safari 網站資料前，請先到 ⚙ 設定 →「匯出備份」。
- 更新網站後，主畫面的 App 重新開啟一次就會載入新版。
